Map

  • Tab moves focus into the map. A visible focus ring appears on the map frame.
  • Arrow keys pan the map.
  • + / - zoom in and out.
  • N re-orients the map to north.
  • Shift + Arrow rotates the view in 3D.
  • Tab again moves focus to the next map widget (Search, Legend, Layers).

Data table

  • The data table shows the same features as the map and stays in sync with it.
  • In the table, Arrow Up / Arrow Down moves between rows; Home / End jumps to the first or last row; Enter selects the row and zooms the map.
  • Per-row actions (Zoom, Buffer, Find Adjoiners, Report, Tax Info, Permits) are real buttons — Tab into them, Enter or Space to activate.
  • Column headers are focusable; Enter or Space toggles sort.
  • Zoom, search, and row-activation results are announced via screen reader.

Query builder

  • Open the builder with the Query builder action in the header.
  • Pick a layer, then a field, then click operator buttons (=, LIKE, AND, …) to assemble a WHERE clause. Run executes the query; results appear in both the map and the data table.

Screen readers

Tested targets per Esri guidance: NVDA + Firefox, JAWS + Chrome, VoiceOver + Safari. With NVDA, if arrow keys do not pan the map, disable Browse Mode (NVDA + Space) while the map has focus.
